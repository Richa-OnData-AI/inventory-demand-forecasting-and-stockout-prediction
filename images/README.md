# Project Visualizations

This folder contains the key visualizations used in the **Inventory Demand Forecasting and Stock-out Prediction** project.

## Visualizations

- **Inventory Trend Analysis** – Monitors inventory movement over time.
- **Top Products Requiring Replenishment** – Identifies products that frequently fall below reorder levels.
- **Supplier Delay Analysis** – Evaluates supplier performance based on delivery delays.
- **Feature Importance (XGBoost)** – Highlights the most influential features used for demand prediction.
- **Actual vs Predicted Demand** – Compares model predictions with actual demand values.
- **Model Performance** – Summarizes the performance of the forecasting model.
- **Reorder Recommendation** – Suggests reorder quantities to improve inventory planning.

These visualizations provide business insights to support inventory optimization and reduce stock-out risks.
